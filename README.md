# Shafin Ahmed — Personal Portfolio

Professional personal website built with [Hugo](https://gohugo.io/) and hosted on GitHub Pages.

## Live site

https://shafin5556.github.io/portfolio/

## Local development

```bash
hugo server -D
```

Open http://localhost:1313/

## Build

```bash
hugo --minify
```

## Content source

Portfolio content is based on `Shafin-Ahmed-Resume.pdf` and maintained in `data/resume.toml`.
